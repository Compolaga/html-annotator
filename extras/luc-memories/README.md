# Luc-workflow memories (niet de skill)

Deze vijf bestanden hoorden historisch in `install.sh`. Ze zijn geen
html-annotator-gedrag: done-prefix, Plannotator, bevindingen-in-document,
feedback-subagents, AskUserQuestion.

`install.sh` kopieert ze **niet**. Bestaande regels in een project-`MEMORY.md`
blijven staan; dit is geen uninstall.

Wil je ze opnieuw in een project: kopieer handmatig naar die memory-map.
